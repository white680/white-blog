## 后端核查

服务端使用 Express 5、TypeScript、MySQL。`routes/index.ts` 当前注册 `GET /`、管理员注册/登录接口以及 `GET /Comment`。尚无面向个人网站的文章、图库、日记、作品或公开资料读取接口。`GET /Comment` 也不能视为经过公开范围与审核规则确认的前台接口。`main.ts` 配置静态目录和面向管理端开发地址的 CORS；这些配置不代表已有媒体上传或公开内容 API。本轮未读取真实 MySQL 记录。

管理端使用 Vue 3、Vite、Yike UI、Mock.js。文章、分类、图库、日记等界面含 Mock 展示与内存操作；现有管理端画面不能作为公共只读接口契约。前台演示内容由本仓库独立编写，不直接复制管理端 Mock。用户提供的接口文档截图中，文章与图库共用 `/createArticle` 写入结构，以 `classify` 区分；当前服务端路由文件尚未注册这个接口，因此截图只能用于理解拟定的数据形态。

## 后台能力与前台映射

个人网站的内容页面面向所有人，无须登录。下表中的“模型”仅指已检查的建表定义或管理端形态，均**不表示公共读取 API 已实现**。`article.classify = 0` 为文章、`1` 为图片；`subset.classify = 0/1/2` 分别为文章、图片、资源分类。管理端 Mock 约定 `article.state = 0/1` 为草稿/发布，正式接口仍需确认服务端筛选。

| 领域 | 当前模型或管理端线索 | 前台现状 | 联调缺口 |
| --- | --- | --- | --- |
| 文章 | `article` 表含标题、简介、正文、封面、状态、时间等；管理端有文章 Mock | 首页、列表、详情、归档显示 6 篇前台 Mock | 已发布文章的公共列表与详情、稳定标识、分页筛选、正文格式和安全规则 |
| 相册 / 图库 | 与文章共用 `article` 表，`classify = 1`；标题、分类、标签、简介、内容、封面、浏览量、状态与时间同属该表 | `/gallery` 和 `/gallery/[id]` 展示 4 组本地图片演示数据，支持分类浏览和图片预览；导航、页脚均有入口 | 已发布图片类内容的公共列表/详情、`content` 图片数组的序列化格式、媒体 URL、分类标签和评论点赞聚合 |
| 分类与标签 | `subset`、`label` 表；文章 `label` 为字符串 | Mock 分类、标签筛选 | 公共分类标签查询及文章关联定义 |
| 作品 | 未见独立作品表或公共接口 | 展示 3 个演示项目 | 确定作品来源、公开字段、封面及详情能力 |
| 片刻 / 日记 | `diary` 表含标题、内容、图片、`weather_id`、心情和时间；`weather` 表提供名称与图标 | 首页摘要及 `/moments` 展示 6 则演示记录；列表以两列错位的多色便利贴呈现标题、正文、天气、心情、日期，支持轻微入场及悬停动效，不渲染正文图片 | 公共读取接口、心情数值含义、天气关联和公开规则；图片字段可保留在数据映射中，但片刻页当前不展示 |
| 个人介绍 | `users` 表含账号资料，设置页未见公开资料流程 | `/about` 使用演示介绍 | 独立的公开资料投影，不暴露管理员私有字段 |
| 媒体 / 资源 | `file` 表保存 URL、名称、格式、所属分类与时间 | 本地图片用于文章和相册的演示；片刻 Mock 中的图片字段暂不渲染 | 稳定公开 URL、资源分类、访问权限及替代文本等元数据 |
| 评论与点赞 | `comment`、`praise` 表关联 `article`，可用于文章及图库 | 详情页目前只展示演示汇总数 | 经审核的评论列表和聚合计数接口；不公开用户标识与举报、已读等管理字段 |
| 账号、私信、访问记录 | `users`、`message`、`record` 表 | 不作为公开内容直接展示 | 若需站点统计，只提供汇总数据；管理员密码、私信正文和原始访问记录不进入公开页面 |

## 技术与风险

- 前台采用 Nuxt 4、Vue 3、TypeScript、pnpm，页面位于 Nuxt 4 的 `app/pages/`。目前没有因未确定接口而预设服务层或运行时 API 地址。
- 文章详情以结构化 Mock 段落渲染，未接收任意 HTML。管理端现有 wangEditor 富文本与原 Prompt 的 Markdown 目标不一致；联调前必须确认存储格式、可信净化位置、图片与代码块处理。
- 真实文章表目前没有已确认的 `slug` 公共路由契约。当前 URL 仅是演示数据的标识，后续需决定沿用 slug、ID 或后端映射。
- 网站浏览无需登录；后台写入和管理仍由后台鉴权。草稿、管理员密码、私信、原始访问记录必须由服务端限定公开边界；前台隐藏字段不能代替服务端授权。
- SEO 已有逐页标题、描述及 Open Graph 基础信息，尚未配置正式域名、canonical、sitemap 或 robots。部署和真实内容确定后补齐。
