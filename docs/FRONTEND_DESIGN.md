# 个人网站前台设计说明

> 2026-10-27 初版。当前目标是供用户完整浏览前端效果；真实内容与参考站细节优化将在后续阶段进行。

## 视觉方向

首页已按 [Lunaris](https://github.com/zxz-qwery/Lunaris) 的 MIT 开源首页改造：雾蓝与深夜蓝形成节奏，大幅人物图建立氛围，主题导航和三栏文章区沿用参考项目的主要构图。Hero 使用其 `apps/web/public/images/home.jpg` 的 WebP 优化版，原图与 [许可声明](../LUNARIS_LICENSE.txt) 一并保留。页眉只显示艺术字 **White**，不显示图形 logo；文章、作品与个人介绍仍来自本站 Mock。其他页面沿用本项目前一版样式，后续再统一细节。

## 页面构图

| 页面 | 当前构图与交互 |
| --- | --- |
| 首页 | 人物图 Hero、主题导航、左作者资料／中间文章／右内容索引、下方作品与片刻记录 |
| 文章 | 宽幅首篇、后续图文列表；分类、标签、搜索、分页可组合使用 |
| 详情 | 通栏封面、正文目录、引文和代码、封面预览、前后篇与相关文章 |
| 作品 | 不等权图文编排，分类切换 |
| 关于 | 介绍、关注方向与工具，末尾引回文章和作品 |
| 归档与片刻 | 按时间组织的紧凑阅读页 |

示例内容是为了把阅读路径和交互做成完整可验收的前端效果，并在页脚明确标注为演示数据。站点不展示虚构的访问统计、评论或社交身份。

## 视觉系统与维护位置

`app/assets/styles/main.css` 管理全站基础规则；首页专属布局和配色在 `app/assets/styles/home.css`，以 `.lunaris-home` 和 `.site-shell--home` 限定作用范围。英文字标优先 Palatino / Georgia 斜体，中文标题优先宋体，正文使用系统无衬线字体。内容版心约 1200px，手机端改为单列和自然滚动。

首页场景位于 `public/images/lunaris-home.webp`，源文件为同目录的 `lunaris-home.jpg`；其他原创 SVG 插画仍位于该目录。替换素材时同时检查宽屏与手机裁切、替代文本和授权。导航在 `app/components/SiteHeader.vue`，页脚在 `SiteFooter.vue`；新增页面遵循 `app/pages/` 文件路由。

## 动效与可用性

悬停使用轻量 CSS 变化；`prefers-reduced-motion` 时关闭装饰性过渡。移动端使用原生 `details` 菜单，路由变化和 Escape 会收起。导航、筛选、搜索、预览弹窗与分页保留文字或语义标记，键盘焦点可见。文章代码复制有成功和失败反馈。当前没有 Yike UI、GSAP、Three.js 等额外依赖。

已对 375、768、1024、1280、1440px 宽度进行浏览器检查，未发现横向溢出。后续根据用户反馈细化参考站的比例、素材与动效时，继续在真实浏览器逐宽度复查。具体已验证行为及未验证项见 [进度记录](FRONTEND_PROGRESS.md)。
