# 前台进度与验收记录

> 更新：2026-10-28。本文记录已完成前端效果；后端业务接口仍待用户开发。

## 已完成

- Nuxt 4 + Vue 3 + TypeScript 工程、全局布局、艺术字 White 页眉与页脚。
- 首页、文章列表与详情、相册列表与详情、作品、关于、归档、片刻记录。站内演示数据集中于 `app/data/mock.ts`，页脚明确标注其性质。
- 文章分类、标签、搜索、分页、目录、封面预览、代码复制反馈、前后篇和相关文章；相册分类、图片预览；作品分类切换。片刻记录以六种浅色便利贴展示标题、正文、天气、心情和日期，不展示图片。
- 原创 SVG 插画、响应式样式、基础逐页 SEO、键盘焦点与减少动态效果支持。
- 未改动管理端、服务端和数据库。未使用 Yike UI；现有需求用原生 HTML、CSS 与 Nuxt 实现。
- 首页已按 Lunaris MIT 首页源码改造为 Nuxt/Vue 实现；引入其 Hero 原图并生成 162 KB WebP（源 JPG 为 5.8 MB），许可与源版本见项目根目录 `LUNARIS_LICENSE.txt`。相册页沿用文章页的线稿背景与毛玻璃；片刻页复用同一张线稿背景并柔化显示，采用两列错位纸签与入场、悬停动效。Mock 图片字段保留供后续数据映射。

## 尚未完成及下一阶段

- **真实业务联调**：服务端没有公共内容 API，当前没有实际请求或数据库验证。个人网站阅读无需登录；待后端准备后按 [API 接入清单](API_INTEGRATION.md) 逐页替换 Mock。
- **正式内容**：演示文章、相册、作品、短记录和简介须由用户真实内容替换。不能将演示数据视为个人经历或已发布作品。
- **正式 SEO 与部署**：域名、canonical、sitemap、robots、缓存和图片策略需结合部署环境确认。
- **后续视觉细化**：用户将依据初版再调整 Lunaris 参考细节；替换素材和改布局后继续做多宽度浏览器检查。
- **视觉检查的保留项**：自动审美规则仍标出细分字体、分隔线、渐变、索引数字及较少实景图等偏差。这些元素属于用户指定的 Lunaris 风格，本轮以参考站结构和视觉还原为先；后续结合用户反馈调整。手机菜单和键盘焦点需在最终预览上再做一次手动交互复查。

建议的下一轮验收用例：文章分类与搜索组合后切换分页；无匹配结果后清空条件；文章详情键盘打开/关闭封面预览；窄屏菜单用 Escape 收起；剪贴板允许与拒绝两种状态；真实接口就绪后验证草稿不可见、404 与请求失败。
